## Project Overview
AI Driven Customer Segmentation is a machine learning-powered analytics system that helps businesses understand customer behavior using K-Means Clustering. The application provides interactive dashboards, customer analytics, segmentation visualizations, and business insights.

## Features
- Interactive Dashboard
- Customer Analytics
- K-Means Customer Segmentation
- Business Insights & Recommendations
- Data Visualization with Plotly
- Streamlit-based Web Application

## Technology Stack
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-Learn
- Plotly
- Joblib

## Installation

Clone the repository:

```bash
git clone https://github.com/Vidyya/ai-driven-customer-segmentation.git
cd ai-driven-customer-segmentation
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
